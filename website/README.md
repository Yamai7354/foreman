# Portfolio site

Randy Johnson's personal/freelance portfolio — Next.js (App Router) + Tailwind v4.
Deployed on Vercel, DNS pointed here from Wix.

Not related to the Foreman CLI tool that lives in the rest of this repo —
this is a personal site that happens to showcase Foreman as one of several
projects.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

Edit content in `app/page.tsx`. Design tokens (colors, fonts) live in
`app/globals.css`.
